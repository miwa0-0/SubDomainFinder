# SubDomainFinder
This is a bruteforce Subdomain finder made with python and uses proxies to prevent ip blocking.

# subdomain.txt
  ~ Here, there is a list of common subdomains of websites.

# subdomain.py
  ~ The script which will find subdomains of the targeted website with out getting rate limited.

# validproxies.txt
  ~ I have provided free valid proxies which help in making requests to targeted subdomain.

If you want to add your own proxies, you can add them in validproxies.txt
If you want to add your own subdomain, you can add them in subdomain.txt
